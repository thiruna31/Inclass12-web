# CampusConnect — Thirunavukkarasu Palaniappa

This project is a four-step student-club registration demo made with HTML, CSS, and JavaScript. Open `index.html` in a modern browser; no installation or internet connection is needed. The Identity page checks a name, campus email, and fictional student ID. The Security page checks password strength and exact confirmation, and its checklist changes as you type. The Profile page asks for a membership tier, one to three interests, an optional short bio, and agreement to the practice terms. The Review page shows non-secret details and lets a user return to edit each section. I used HTML constraints alongside shared JavaScript rules, with blur checks, input correction, and full final validation. One trade-off is that the multi-select uses a native control, which is accessible but less obvious on some devices; instructions explain how to select several items. This is a client-only class exercise: it creates no real account, sends no data, and intentionally does not save entries across refreshes.
